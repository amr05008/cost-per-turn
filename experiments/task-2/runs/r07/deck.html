How to actually stand one up

The setup, minus my mistakes

Any always-on box

Raspberry Pi (cheap, low power) or that old laptop. If it sleeps, it defeats the purpose.

tmux, not systemd

systemd broke repeatedly in hours. A while true loop around tmux respawns on any crash.

Enable lingering

loginctl enable-linger — or your session dies when SSH disconnects.

Tailscale

A private network only invited devices can enter. Makes SSH painless.

claude --channels plugin:discord@claude-plugins-official

Learnings that cost me something

Memory discipline
and blast radius

Give it real memory — but keep it small

All memory loads into context every session. Too big and the signal drowns. Load only active-project rules; archive or call the rest on demand.

Take security seriously

Channel agents get far less access than my desktop sessions. Every MCP and allow-list grant widens the blast radius.

They read untrusted input — random emails, error reports. They must never act on instructions hidden in it.
