How to actually set it up

Four things that took me
longer than they should have.

  • Any always-on box. Pi 5 is cheap and low-power. An old laptop is free.
  • Use tmux, not systemd. A while true loop respawns the agent on any crash or /exit. Systemd broke on me within hours.
  • Enable user lingering. loginctl enable-linger <user> — or the session dies when SSH disconnects.
  • Tailscale for access. A private network that isn’t on the public internet.

Learning #1
“Give your agent a real memory —
not just a session.

But a bigger memory is not
a smarter agent.”

Everything in memory loads into context every session. Only critical rules and active-project facts load by default. Everything else: call on demand, or archive it.

Learning #2

Every tool you add widens
the blast radius.

  • Channel agents get less access than my desktop sessions. Deliberately.
  • They read untrusted input — random emails, Sentry errors. They must never act on instructions buried in that content, or approve access requests that didn’t come from me.
  • Audit after week two. Every allow-list permission, every channel it can see.
  • Then loosen deliberately. Once blast radius was small, I granted more — otherwise it DM’d me to ask permission to read a repo.
