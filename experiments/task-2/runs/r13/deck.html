Internal PM Session

Go get yourself
a personal agent.

The most useful thing I built this year — and now the foundation everything else sits on.

The Setup

Two always-on agents,
one shared brain.

Pi Pi

Lives on a Raspberry Pi 5. Cheap, low power, never sleeps.

Agent M1

Lives on an old laptop. More horsepower, more storage, more trust.

One memory layer

Synced through GitHub every ~4 hours. One learns it, both know it.

Reached from Discord

Phone, laptop, anywhere. No SSH required.

Runs inside a Claude Max plan — the $100 tier, not the $200. Side projects add variable API cost.

How It's Wired

Four boring pieces.

Claude Channels

Connects a Claude Code session to Discord. The plugin forwards your message, the agent replies in the chat.

An always-on machine

A Pi 5, or that old laptop in your drawer. If it turns off, the agent disappears.

tmux + while true

systemd broke in hours. tmux respawns on crash or /exit. Learn from my mistakes.

Tailscale + linger

Private network in, and the session survives you closing SSH.

claude --channels plugin:discord@claude-plugins-official

Scaling Out

Two agents,
working in parallel.

Pi Pi — the assistant

Questions, capture, planning. Deliberately narrow tool access.

Agent M1 — the operator

Read/write on my app, Sentry + PostHog MCPs. Investigates and submits PRs, with guardrails.

One afternoon, away from my desk: M1 debugged why my app wasn't live in the EU while Pi Pi worked through finance questions. Both from my phone.

Learning 1 of 3

Memory is a
curation problem.

Less is more.

Everything in memory loads into context every session. Let it grow and the agent misses what matters in the noise.

Mine loads only critical rules and active projects. Everything else is called on demand — or archived.

Learning 2 of 3

Take security
seriously.

Untrusted input is the threat

These agents read random emails and error logs. They must never act on instructions buried in that content.

Blast radius grows with access

Every extra tool, MCP and allow-list rule makes a failure bigger. My Channel agents get far less than my desktop sessions.

Audit after week two

Sit down with the agent and review every permission and every channel it can see.

Then loosen, carefully

Too tight and it DMs you to approve reading a repo. Grant more only as the blast radius shrinks.

Learning 3 of 3 — and what's next

Expect to tinker.
Not much.
